# Traductor Español–LSC con Avatar 3D

Proyecto para explorar la traducción de voz en español colombiano a Lengua de
Señas Colombiana (LSC), representada mediante un avatar 3D.

> Estado: documentación inicial del PMV. Aún no se ha iniciado la implementación.

La documentación del proyecto comienza en [docs/README.md](docs/README.md).

## Forma de trabajo

Cada cambio se documenta, verifica, registra en Git y se sube al repositorio
remoto. Las reglas se encuentran en [CONTRIBUIR.md](CONTRIBUIR.md), el detalle
para documentar funciones está en
[docs/09-desarrollo/estandar-documentacion-y-cambios.md](docs/09-desarrollo/estandar-documentacion-y-cambios.md)
y el historial legible se mantiene en [CAMBIOS.md](CAMBIOS.md).

## Alcance preliminar

- Entrada mediante voz o texto en español (`es-CO`).
- Dominio cerrado de saludos y necesidades cotidianas.
- Traducción mediante intenciones y reglas validadas, no sustitución palabra a palabra.
- Reproducción de animaciones creadas en Blender sobre un avatar 3D.
- Aplicación web operada inicialmente por una sola persona desarrolladora.
