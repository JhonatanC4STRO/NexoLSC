# Definición de terminado

**Versión:** 0.1
**Estado:** Propuesta

## Para una historia de software

- [ ] Cumple todos sus criterios de aceptación.
- [ ] Tiene pruebas relevantes y estas pasan.
- [ ] Maneja estados de error y recuperación.
- [ ] No introduce claves, audio o datos personales en logs o repositorio.
- [ ] Es operable por teclado cuando aplica.
- [ ] La documentación afectada está actualizada.
- [ ] Se demostró en el flujo real, no solo de forma aislada.

## Para una intención LSC

- [ ] Propósito y ejemplos positivos/negativos definidos.
- [ ] Guion revisado por una persona competente en LSC.
- [ ] Clips con versión y fuente registradas.
- [ ] Compatibilidad de rig verificada.
- [ ] Revisión manual, no manual y de transiciones aprobada.
- [ ] Prueba de comprensión registrada.
- [ ] Estado cambiado a `VALIDADA` para la versión exacta.

## Para un clip Blender

- [ ] Nombre y rango correctos.
- [ ] Action incluida en la exportación.
- [ ] Sin deformaciones o intersecciones graves.
- [ ] Reproduce en visor glTF y en la aplicación.
- [ ] Manos, rostro y torso visibles.
- [ ] Registro actualizado en el catálogo.

## Para un sprint

- [ ] Existe un incremento demostrable.
- [ ] La documentación coincide con lo implementado.
- [ ] Métricas del incremento fueron registradas.
- [ ] Riesgos y backlog fueron revisados.
- [ ] Se escribió una retrospectiva con máximo tres acciones.
