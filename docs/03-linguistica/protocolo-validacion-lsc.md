# Protocolo de validación LSC

**Versión:** 0.1
**Estado:** Borrador sujeto a acuerdo con las personas validadoras

## Objetivo

Evitar que una animación técnicamente correcta se publique con significado,
gramática, expresión o variante inadecuados.

## Participantes mínimos

- Una persona sorda usuaria competente de LSC para revisión lingüística.
- Idealmente tres o más usuarios de LSC para prueba de comprensión.
- La persona desarrolladora como observadora y responsable de correcciones.

La validación no debe basarse únicamente en la opinión de la persona que anima o
programa.

## Proceso por intención

1. Documentar el propósito y los ejemplos españoles.
2. Acordar el guion LSC y la variante regional.
3. Registrar una referencia autorizada para animación.
4. Producir la animación o secuencia.
5. Revisar configuración manual, orientación, ubicación, movimiento, ritmo,
   componentes no manuales y transiciones.
6. Mostrar la animación sin texto fuente a participantes de comprensión.
7. Registrar respuestas sin inducir la intención esperada.
8. Corregir y repetir si no cumple el umbral.
9. Marcar la versión exacta como `VALIDADA`.

## Escala de revisión experta

| Dimensión | Resultado |
|---|---|
| Forma manual | Aprobada / Ajustar / Rechazada |
| Movimiento y ubicación | Aprobado / Ajustar / Rechazado |
| Componentes no manuales | Aprobados / Ajustar / Rechazados |
| Gramática y orden | Aprobados / Ajustar / Rechazados |
| Variante y contexto | Aprobados / Ajustar / Rechazados |
| Naturalidad y legibilidad | Aprobadas / Ajustar / Rechazadas |

Una dimensión rechazada impide publicar.

## Prueba de comprensión

- Mostrar la animación sin subtítulo ni audio.
- Preguntar qué entendió la persona, con respuesta abierta.
- Registrar si coincide con la intención, es parcialmente correcta o incorrecta.
- Umbral inicial propuesto: 80 % de coincidencia entre participantes.
- Con menos de cinco participantes, reportar resultados como exploratorios y no
  como evidencia estadística.

## Consentimiento y datos

- Explicar propósito, uso y duración de la prueba.
- Solicitar consentimiento antes de grabar imagen, voz o respuestas identificables.
- Permitir retiro sin consecuencias.
- Guardar la mínima información necesaria.

## Registro de validación

```text
Intención:
Versión de guion:
Versión de animaciones:
Región/contexto:
Fecha:
Revisión lingüística:
Participantes de comprensión:
Resultado:
Correcciones pendientes:
Decisión: APROBADA / AJUSTAR / RECHAZADA
```
