# Referencias normativas y técnicas

**Versión:** 0.1
**Estado:** Borrador

## Requisitos

- IEEE 830-1998, norma sustituida:
  <https://standards.ieee.org/ieee/830/1222/>
- ISO/IEC/IEEE 29148:2018, ingeniería de requisitos:
  <https://www.iso.org/standard/72089.html>

La SRS del proyecto se inspira en ISO/IEC/IEEE 29148, pero no pretende declarar
cumplimiento formal con la norma.

## Lengua de Señas Colombiana

- Diccionario virtual bilingüe LSC–español de INSOR:
  <https://educativo.insor.gov.co/catdiccionario/cotidiano/>

El diccionario es una fuente de consulta, no una autorización para copiar o
redistribuir videos o contenido sin revisar sus condiciones de uso.

## Voz
